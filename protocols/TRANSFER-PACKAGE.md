# Paquet de transfert vers l’application

Un changement ne quitte le cerveau que si le paquet contient :
- identifiant et objectif ;
- base exacte de `schoolsafemm` ;
- spec et plan approuvés ;
- commits/branches candidats ;
- fichiers à ajouter/modifier/supprimer ;
- tests exécutés et résultats ;
- vérification sécurité ;
- risques connus ;
- procédure de rollback ;
- critères d’acceptation ;
- statut de revue indépendante ;
- instruction de staging ;
- champ `Autorisation production` vide tant que l’utilisateur n’a pas explicitement validé.

Le paquet est un contrat de transfert, pas une autorisation automatique.
