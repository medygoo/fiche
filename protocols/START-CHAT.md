# Protocole — Début d’un nouveau chat

1. Lire `governance/SCHOOLSAFE-LAWS.md`.
2. Lire `CONTROL-TOWER.md`, `CURRENT-STATE.md`, `HANDOFF.md`.
3. Identifier explicitement dépôt cible, branche, base et objectif.
4. Vérifier GitHub ; ne pas supposer que l’état mémorisé est encore vrai.
5. Charger seulement les décisions/specs/plans nécessaires.
6. Si le code requis dépasse le contexte, produire un paquet Repomix ciblé avec exclusions de secrets.
7. Ne commencer une modification qu’après confirmation du périmètre et du gate applicable.
