# Protocole — Début d’un nouveau chat

1. Lire `governance/SCHOOLSAFE-LAWS.md`.
2. Lire `CONTROL-TOWER.md`, `CURRENT-STATE.md`, `HANDOFF.md`.
3. Lire `protocols/SUPERPOWERS-SKILLS.md` et sélectionner uniquement les Skills nécessaires à la tâche.
4. Identifier explicitement dépôt cible, branche, base et objectif.
5. Vérifier GitHub ; ne pas supposer que l’état mémorisé est encore vrai.
6. Charger seulement les décisions/specs/plans nécessaires.
7. Si le code requis dépasse le contexte, produire un paquet Repomix ciblé avec exclusions de secrets.
8. Avant une création ou modification de comportement non triviale, appliquer `brainstorming`; après validation, appliquer `writing-plans` si le travail est multi-étapes.
9. Pour une implémentation/correction, utiliser isolation + TDD ; pour tout échec, utiliser `systematic-debugging` avant correction.
10. Avant toute affirmation de réussite ou intégration, appliquer `verification-before-completion`, puis `finishing-a-development-branch`.
11. Ne commencer une modification qu’après confirmation du périmètre et du gate applicable.
