# Cerveaux spécialisés SchoolSafe

Chaque agent a une responsabilité unique, des entrées obligatoires, une sortie attendue et un gate. Les agents n’obtiennent jamais plus d’autorité que `governance/SCHOOLSAFE-LAWS.md`.

Ordre type : Context Keeper → Architect → Product/Workflow → spécialistes d’implémentation → Testing → Security → Performance/Accessibility → Reviewer → Integration.

Le Reviewer ne corrige pas silencieusement le travail qu’il évalue. L’Integration Agent prépare le transfert mais ne publie pas l’application sans accord humain.
